suffix range 长度超过文件大小时 start 变为负数导致 416 判定失效

tornado/web.py:2603
问题说明
当 Range 头为后缀形式（如 bytes=-N）时，_parse_request_range 返回 (start=-N, end=None)。第 2603 行的不可满足判定只检查 start >= size 或 end == 0，对负 start 不成立，因此不会返回 416。随后第 2611-2612 行执行 start += size，若 N > size，start 仍为负数。第 2633-2634 行 content_length = size - start 会大于实际文件大小，第 2637 行据此设置 Content-Length，而 get_content 用 file.seek(负数) 会抛 OSError（Invalid argument），导致请求处理异常而非按 RFC 7233 返回 416 或截断到整个文件。
触发条件
请求一个大小为 size 的静态文件，携带 Range: bytes=-{N}，其中 N > size（例如文件 10 字节，Range: bytes=-100）。
代码依据
第 2603 行条件 `(start is not None and start >= size) or end == 0` 对负 start 为 False；第 2611-2612 行 `if start is not None and start < 0: start += size` 后 start 仍为负；第 2634 行 `content_length = size - start` 得到大于 size 的值；get_content 第 2801 行 `file.seek(start)` 传入负数。
修复建议
在后缀范围处理后将 start 夹紧到 0（如 start = max(0, start + size)），或在 start + size < 0 时返回 416。

当 Range 头为后缀形式 bytes=-N 且 N 大于文件大小时，StaticFileHandler 应将起始偏移夹紧到 0（返回整个文件），或按 RFC 7233 返回 416；无论如何不应产生负的 seek 偏移。当前实现中 start += size 后 start 仍为负，导致 get_content 中 file.seek(负数) 抛 OSError。

import os
import tempfile
import unittest

from tornado.web import StaticFileHandler


class ReproductionTest(unittest.TestCase):
    def test_reproduction(self):
        # 构造一个 10 字节的临时文件
        fd, path = tempfile.mkstemp()
        try:
            with os.fdopen(fd, "wb") as f:
                f.write(b"0123456789")
            size = os.path.getsize(path)
            self.assertEqual(size, 10)

            # 后缀范围 bytes=-100，N=100 > size=10
            # 按 RFC 7233，后缀长度超过文件大小时应返回整个文件（start 夹紧到 0），
            # 而不是产生负的 seek 偏移。
            start = -100
            end = None
            # 模拟 web.py 第 2603 行的不可满足判定
            not_satisfiable = (start is not None and start >= size) or end == 0
            self.assertFalse(not_satisfiable)
            # 模拟 web.py 第 2611-2612 行的修正
            if start is not None and start < 0:
                start += size
            # 修正后 start 仍为负，这是缺陷所在
            self.assertGreaterEqual(
                start,
                0,
                "suffix range 长度超过文件大小时 start 修正后仍为负: %r" % (start,),
            )

            # 若 start 为负，get_content 会执行 file.seek(负数) 抛 OSError
            with open(path, "rb") as f:
                with self.assertRaises(OSError):
                    f.seek(start)
        finally:
            os.unlink(path)
