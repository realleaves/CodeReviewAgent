相反参考版本还失败不能自动判假：参考修复只修指定问题。只有PySnooper-3在本轮相反版本通过；其余均失败，其中DFXP对照失败原因变为KeyError，不能说原症状两边相同。相反版本的源码行可能偏移，其gate标签不用于判定跨版本真假，实际异常与源码单独核查。
