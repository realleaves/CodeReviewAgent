字符串过滤器取反逻辑错误：对函数对象取非而非调用结果

youtube_dl/YoutubeDL.py:1081
问题说明
在字符串过滤器分支中，当 filter_spec 含取反前缀（如 '!ext=mp4'）时，代码执行 `op = lambda attr, value: not str_op`。str_op 是函数对象，其真值恒为 True，因此 `not str_op` 恒为 False。该 lambda 无论 attr/value 为何都返回 False，导致所有带取反的字符串过滤器把每个格式都判为不匹配，过滤结果与预期完全相反。正确写法应为 `op = lambda attr, value: not str_op(attr, value)`。
触发条件
调用 _build_format_filter('!ext=mp4') 得到 _filter，再对任意格式 f（如 {'ext':'mp4'} 或 {'ext':'webm'}）调用 _filter(f)，均返回 False。
代码依据
第1080-1083行：`if m.group('negation'): op = lambda attr, value: not str_op` else: `op = str_op`。lambda 体内 `not str_op` 对函数对象取非，恒为 False，未调用 str_op(attr, value)。
修复建议
改为 `op = lambda attr, value: not str_op(attr, value)`，使取反作用于实际比较结果。
复核理由
